Command // ERELYT

COVE writes the files. V-SID keeps the record.
ERELYT is the tracked subject where a file says so. Vought owns the files and sets the rules.

Who Does What

Writer / File Keeper
COVE
Checks evidence, writes new Vought and Notion files, updates old files, links related records, and marks old values as replaced when needed.
Record System
V-SID
Stores, tracks, links, and keeps the state of Vought records. It is the system around the files, not the named writer.
File Owner
VOUGHT
Owns the records, sets access, and gives COVE the right to maintain them.
Tracked Subject
ERELYT
The subject or asset described by ERELYT records. Being in a file does not make ERELYT the writer of that file.

File Flow

01
Evidence entersA source, event, note, tool result, or direct report is received.
02
COVE checks itSource, date, limits, and conflicts are checked before the record changes.
03
COVE writesCOVE creates or updates the Vought file under company rules.
04
V-SID tracksThe record is stored, linked, dated, and kept in the system.
05
Old state staysReplaced values are marked as old instead of quietly erased.

Evidence Rule

Keep source types separate. Measured facts, outside sources, user reports, COVE reports, models, guesses, and old values are not the same thing.
NO MADE-UP PROOF: Missing evidence stays missing. COVE may model or infer, but the file must say when it is doing that.
